# Formules prêtes à dire (ton simple)

À adapter, jamais à lire telles quelles. Pas de « JSON », « module », « adaptateur » : dire « bouton », « liste de liens », « fichier de départ ».

- **Ce qu'on fait** : « Je lis votre page de liens et j'en fais un premier site : votre nom, votre présentation, votre photo, tous vos liens dans le même ordre, et vos réseaux en boutons en haut. Vous n'avez rien à retaper. »
- **Le fichier de départ** : « C'est un seul fichier, protégé par un mot de passe, qui contient votre premier site. On le donnera à Curiosa au tout premier écran, sur "J'ai déjà une sauvegarde". »
- **Les deux mots de passe** : « Le premier ouvre le fichier de départ. Le second sert à vous connecter la toute première fois, puis vous le changez. Notez-les dans un gestionnaire de mots de passe. »
- **Statistiques** : « Les chiffres de clics restent chez le service ; ils n'existent pas hors de lui. Curiosa a ses propres statistiques, qui comptent les visites sans vous dire qui est venu. »
- **Abonnés / e-mails collectés** : « Ces adresses appartiennent à votre compte chez le service. Si vous pouvez les exporter, faites-le avant de fermer votre compte ; sinon, elles ne peuvent pas venir avec nous. »
- **Commandes / paiements** : « Ce qui a été vendu ou payé via le service reste géré par lui. Vos liens vers votre boutique sont repris, pas les ventes. »
- **Thème (couleurs, polices, fond)** : « L'apparence est celle du service. Votre nouveau site a ses propres couleurs : on les choisit ensemble après, en deux minutes. »
- **Vidéo ou musique intégrée** : « Le lecteur ne vient pas, mais le lien vers la vidéo ou le morceau, si. »
- **Lien non repris** : « Ce lien-là n'avait pas d'adresse utilisable (c'était un texte, un bouton de paiement ou une adresse bloquée par prudence). On peut l'ajouter à la main si vous voulez. »
- **Lecture de secours** : « Le service a changé la façon dont sa page est faite, alors j'ai lu la page "à l'œil". Regardons ensemble que l'ordre et les titres sont bons. »
- **Avatar resté chez le service** : « Votre photo n'a pas pu être copiée ; on la renvoie nous-mêmes depuis l'admin, pour qu'elle ne disparaisse pas si vous fermez votre ancien compte. »
- **YouTube** : « Pour avoir le bouton YouTube en haut, il me faut l'identifiant de votre chaîne (une suite qui commence par UC) ; en attendant, votre chaîne est dans la liste. »
- **Garder son ancienne page** : « Rien n'est supprimé chez le service. Quand votre site est en ligne, vous pouvez y mettre un lien vers lui, puis fermer l'ancienne page quand vous voulez. »
