# Captures de la revue du mode simple (hors diff de la PR)

Site neuf, une personne propriétaire (« Emma »), mode simple par défaut. 1280 px et 390 px, pleine page, JPEG.
- avant/ : le code de dev au départ (suffixe `__simple__` / `__advanced__`, puis la largeur)
- apres/ : le code de la PR (mêmes pages, mêmes réglages)
- modules/ : 23 extensions installées, chaque onglet, mode simple, avant correction (aucun module n'est modifié par la PR)
- assistant/ : l'assistant d'installation /admin/setup
Le site contient 23 extensions (Participation, Bot Twitch, Planning, Sondages, Événements, Galeries, FAQ, Liens, Témoignages, Commandes, Contacts, Home Assistant, Discord, Instagram, Jeu du jour, Suggestions de jeux, Mur des remerciements…).
