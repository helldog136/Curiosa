# Mon skin

Un skin de départ pour Curiosa : clair et sombre, titres à empattement, cartes légères. Il ne change que l'apparence.

- **Polices** : aucune police embarquée (piles du système).
- **Licence** : MIT (voir `LICENSE`).
- **Tester** : `npm run skin:check -- <ce dossier> --visual` puis `npm run skin:bench -- <ce dossier>` depuis le cœur de Curiosa.
