# Philosophie de licence (à appliquer par défaut à tous les projets de l'auteur)

Voulue par l'auteur : le code est **ouvert et lisible**, mais il **reste sa propriété** et on lui en doit le crédit. Concrètement, pour un nouveau projet :

- **Usage libre** pour la propre activité de l'utilisateur, **y compris commerciale** (son site, sa boutique, ses sponsors).
- **Interdit** : vendre le logiciel ou une version modifiée, le revendre en abonnement ou en service hébergé à d'autres.
- **Crédit obligatoire**, visible dans l'interface (« Powered by <Projet> », le nom étant un lien vers le dépôt) et dans les mentions d'auteur du code.
- **Propriété** conservée par l'auteur ; un fork reste sous la même licence.
- **Modules / extensions de tiers** : hors périmètre, leur auteur choisit sa licence, garde le mérite et peut les vendre.
- Les versions déjà publiées sous une autre licence (MIT) le restent pour ceux qui les ont reçues.
- Travail de mise en forme juridique : faire relire le texte par un juriste avant une release stable.

Modèle d'application : `LICENSE` de ce dépôt (Curiosa License 1.0), `src/core/credit.ts` et le pied de page public et d'admin.
