# Mon module

Un modèle de module pour Curiosa. Une fois installé, il affiche un court message d'accueil sur la page d'accueil du site.

## Réglages

- **Message d'accueil** : la phrase affichée. Si vous la videz, le module affiche « Bienvenue ! ».
- **Signature** (facultatif) : une ligne sous le message.

## Limites

C'est un exemple : il ne stocke rien et ne collecte aucune donnée sur les visiteurs.

## Pour les développeurs

Copiez ce dossier, changez l'identifiant dans `module.json`, puis lancez `npm run module:check -- <votre-dossier>` depuis le dépôt du cœur : tout ce qui est marqué ❌ est à corriger.
